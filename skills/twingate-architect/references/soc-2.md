# SOC 2 Report

## Page Title
SOC 2 Report

## Summary
Twingate holds a SOC 2 Type 2 certification, audited by an independent third party per AICPA frameworks. The report covers security controls tested over a period of time (not a single point-in-time snapshot). Access to the report is available to existing customers via a trust portal.

## Key Information
- **SOC 2 Type 2**: Controls tested over a time period, not just a single point in time
- **Scope**: Security controls and Trust Services Criteria
- **Auditor**: Independent third party
- **Report access**: Available at [trust.twingate.com](https://trust.twingate.com)
- **Access expiration**: 30 days after access is granted
- **Access process**: Requests are reviewed and manually approved by Twingate team

## Prerequisites
- Must be an existing Twingate customer to request the report via trust portal
- Non-customers must contact the Twingate customer team directly

## How to Request Access
1. Navigate to [trust.twingate.com](https://trust.twingate.com)
2. Submit an access request
3. Twingate team reviews and grants access
4. Download/review report within the 30-day access window

## Gotchas
- Access expires after **30 days** — download or review the report promptly after access is granted
- Access is not self-service; requests require manual review/approval
- Prospective customers cannot use the trust portal — must contact the sales/customer team separately
