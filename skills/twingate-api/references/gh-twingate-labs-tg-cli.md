# Twingate CLI (tg-cli)

## Summary
A command-line tool for administering Twingate via its API. Supports exporting network topology data (Excel/PNG), listing resources, and importing groups, remote networks, and resources between accounts.

## Key Information
- Written in Deno/TypeScript; distributed as pre-compiled binaries
- Supports Windows, Linux, and macOS (x86_64)
- Export PNG output requires GraphViz installed and on PATH
- Import format must match the export command output exactly

## Prerequisites
- Twingate account with API access
- Pre-built binary: download from [releases](https://github.com/Twingate-Labs/tg-cli/releases/latest)
- **PNG export only:** [GraphViz](https://graphviz.gitlab.io/download/#executable-packages) installed and on PATH
- **Building from source:** [Deno](https://deno.land/#installation) runtime

## Usage / Step-by-Step

**macOS setup (required before first run):**
```bash
xattr -d com.apple.quarantine /path/to/tg
chmod +x /path/to/tg
```

**Common commands:**
```bash
./tg --help                          # Top-level help
./tg group --help                    # Group subcommand help
./tg export                          # Export to Excel
./tg export --format png             # Export to PNG (requires GraphViz)
./tg resource list                   # List all resources
./tg import -a <account> -nrg -f <file>  # Import groups, networks, resources
```

**Build from source:**
```bash
deno bundle --unstable --import-map ./import_map.json ./tg.js ./tg.bundle.js
deno compile --allow-all --unstable --target x86_64-unknown-linux-gnu --output ./tg ./tg.bundle.js
```

## Configuration Values

| Flag | Description |
|------|-------------|
| `-a` | Target account name (used with `import`) |
| `-f` | Path to import file |
| `-nrg` | Import remote networks, resources, and groups |
| `--format` | Export format (`png`; default is Excel) |

*Note: API credentials/configuration details are not documented in the README; check `--help` output or source for required env vars or config file.*

## Gotchas
- **macOS quarantine:** Must run `xattr -d com.apple.quarantine` before executing; binary will be blocked otherwise
- **PNG export dependency:** GraphViz must be on PATH, not just installed
- **Import file format:** Must use files generated by the `export` command; arbitrary formats are not supported
- **Deno compile target:** The source build example targets `x86_64-unknown-linux-gnu` only; adjust `--target` flag for other platforms
- Build uses `--unstable` flag, indicating reliance on unstable Deno APIs
