# Twingate + ZScaler Compatibility

## Page Title
ZScaler Integration with Twingate Client

## Summary
ZScaler intercepts Twingate's TLS sessions on Windows, causing SSL certificate validation failures. Resolution requires either removing ZScaler or configuring SSL inspection bypass rules for Twingate domains.

## Key Information
- ZScaler intercepts Twingate TLS sessions, returning invalid certificates
- ZScaler service runs in background even when user has "exited" the app
- Issue confirmed on **Windows only**; macOS/Linux untested but same resolution applies
- Two resolution paths: full ZScaler removal OR configuration-based coexistence

## Symptoms
```
[WARN] SSL check error from host: .twingate.com. SSL Certificate is not pinned!
[ERROR] Failed to validate controller url - AuthenticationException: 
        The remote certificate is invalid according to the validation procedure.
```

## Prerequisites
- Access to ZScaler admin console
- ZScaler Client Connector Portal access
- Admin rights on Windows device

## Step-by-Step (Coexistence Configuration)

**Step 1: Create SSL Inspection Bypass Group**
- Navigate: `Administration → IP & FQDN Groups → Destination IPv4 Groups`
- Create new group for SSL inspection bypass
- Add entry: `.twingate.com`

**Step 2: Add Hostname Bypass for VPN Gateway**
- Navigate: `Policy → Zscaler Client Connector Portal → Windows`
- Edit applicable policy
- Under `HOSTNAME OR IP ADDRESS BYPASS FOR VPN GATEWAY`, add:
  ```
  <your-tenant-name>.twingate.com
  ```

**Step 3: Push Policy Update**
- Update policy on ZScaler local agent

## Configuration Values

| Field | Value |
|-------|-------|
| SSL Bypass Domain | `.twingate.com` |
| VPN Gateway Bypass | `<tenant>.twingate.com` |

## Gotchas
- Simply **exiting** ZScaler UI is insufficient — the Windows service continues running and intercepting traffic
- ZScaler must be fully **stopped and disabled** at the service level, not just closed from system tray
- macOS/Linux compatibility unconfirmed; apply same resolution if issues occur
- Both Step 1 (SSL inspection bypass) AND Step 2 (VPN gateway bypass) are required for coexistence
