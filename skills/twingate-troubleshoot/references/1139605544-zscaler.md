# Using Zscaler alongside Twingate

## Summary
Zscaler Client Connector on Windows can intercept the Twingate TLS session, so the Twingate Client sees an invalid certificate and cannot open secure channels. The fix is to uninstall or disable Zscaler, or to configure Zscaler to bypass SSL inspection and VPN gateway handling for Twingate domains.

## Key Information
- Applies to: Twingate Client on Windows with Zscaler Client Connector. Other platforms are untested, but the resolution is expected to be the same.
- The Zscaler service runs even when the client is not connected.
- Exiting the Zscaler program is not sufficient to stop the interference.
- Running both together works only in some cases, with the bypass configuration below.

## Prerequisites
- Admin access to the Zscaler admin console and the Zscaler Client Connector Portal.
- Your Twingate tenant name (`<tenant>.twingate.com`).
- Access to `Twingate.log` on the Windows device for diagnosis.

## Symptoms (Twingate.log)
- `[WARN] [client] SSL check error from host: <twingate_network>.twingate.com. SSL Certificate is not pinned! [ApiCertificateValidationService.Callback]`
- `[ERROR] [client] Failed to validate controller url [ControllerServerValidator.ValidateAsync]` with `HttpRequestException` / `WebException`: "Could not establish trust relationship for the SSL/TLS secure channel", and `AuthenticationException`: "The remote certificate is invalid according to the validation procedure."

## Step-by-Step

**Option 1: Remove Zscaler**
1. Uninstall Zscaler, or stop the Zscaler service and set it to disabled.

**Option 2: Bypass configuration**
1. In the Zscaler admin console, go to Administration → IP & FQDN Groups → Destination IPv4 Groups.
2. Create a group for SSL inspection bypass and add `.twingate.com`.
3. Go to Policy → Zscaler Client Connector Portal → Windows.
4. Edit the applicable policy, find HOSTNAME OR IP ADDRESS BYPASS FOR VPN GATEWAY, and add `<tenant>.twingate.com` as an exception.
5. Update the policy on the Zscaler local agent.

## Configuration Values
- SSL inspection bypass group entry: `.twingate.com`
- VPN gateway bypass entry: `<tenant>.twingate.com` (replace `<tenant>` with your tenant name)

## Gotchas
- Closing the Zscaler app does not stop its service. You must stop and disable the service or uninstall.
- The bypass approach works only "in some cases," so fall back to Option 1 if it fails.
- The Zscaler policy must be updated on the local agent after changes, or they won't take effect.
- macOS and Linux are unverified.
